# Movie Ticket Booking Backend

## Overview
This repository contains the backend implementation for a **Movie Ticket Booking System**. It provides a set of RESTful APIs to manage movies, theaters, showtimes, ticket bookings, and user authentication. The application is designed to be scalable, efficient, and easy to integrate with frontend applications.

## Features
- **Movie and Theatre Management** – Add, update, and retrieve movie and theater details.
- **Showtime Scheduling** – Manage schedules for different movies at multiple theaters.
- **Ticket Booking** – Book and cancel tickets with real-time seat availability.
- **User Authentication** – Secure authentication and role-based access control.
- **Payment Integration (Future Scope)** – Support for integrating payment gateways.
- **Logging and Monitoring** – Tracks API requests, errors, and performance metrics.

## Technology Stack
- **Backend:** Java, Spring Boot
- **Database:** PostgreSQL / MySQL
- **Authentication:** JWT-based authentication
- **API Documentation:** Swagger / OpenAPI
- **Deployment:** Docker, Kubernetes (optional)
